Windows 10/11 x64 桌面轮盘，启动入口：双击 `dist\RadialMenu.exe`

## 使用

- 按住左 Alt 呼出轮盘，移向软件，松开 Alt 打开或切换到前台；最小化窗口会恢复。
- 回到中心松开、按 Esc 或新按下鼠标左键均可取消。左键点击任意位置都生效，取消后须松开 Alt 才能再次呼出。
- 绑定时先拖住 `.exe` 或 `.lnk`，再按住左 Alt，移到目标扇形并松开鼠标。快捷方式解析为实际程序，保留参数和工作目录。绑定不弹 Windows 通知，失败原因在轮盘内显示。
- 移到右下角齿轮后松开 Alt，或双击托盘图标打开设置。
- 设置支持 3～12 格、RGB 高光、大小、倾斜、回弹和展开角度。减少格子只隐藏多余绑定，增加后恢复。
- 开机启动可在设置中开启，默认关闭。Alt+Tab 等系统组合键保持原用途。
